 2. โครงสร้างเมนูฝ่ัง Admin (Admin Dashboard Interface)
ฝั่ง Admin ถูกออกแบบมาส าหรับการท างานบน Desktop หรือ Tablet มีเมนูที่ครอบคลุมการบริหารจัดการ
ทั้งหมด 4 เมนูหลัก
Plaintext
 [ส่วนหัว Admin Control Panel  แสดงชื่อ Admin  ปุ่ ม Logout]
 │
 └── ☰ แถบเมนูหลัก (Main Navigation Bar)
 │
 ├── 1. บันทึกข้อมูล (Entry Form)
 │ └─► ฟอร์มบันทึกการใช้งานเติมน ้ามัน (ใช้ชุดเดียวกับ User)
 │
 ├── 2. จัดการข้อมูลการใช้งาน (Usage Logs Management)
 │ ├─► [ Search Bar] ค้นหาด้วย ชื่อคน, ทะเบียน, วัตถุประสงค์
 │ ├─► [ Date Filter] ตัวกรองเลือกช่วงวันที่
 │ └─► [ Data Table] ตารางแสดงรายการวิ่งรถ
 │ • แสดงข้อมูลครบถ้วน + ค านวณระยะทางให้อัตโนมัติ
 │ • Action Buttons [ แก้ไข ] [ ลบ ]
 │
 ├── 3. จัดการข้อมูลน ้ามัน (Fuel Logs Management)
 │ ├─► [ Search & Filter Controls]
 │ └─► [ Data Table] ตารางแสดงรายการเติมน ้ามัน
 │ • แสดงยอดเงิน  ปริมาณลิตร  สลิป
 │ • Flagging Highlight ไฮไลต์แถบ สีแดง หากรายการไหนเกินงบ (Over-budget)
 │ • Action Buttons [ แก้ไข ] [ ดูรูปสลิป ] [ อนุมัติ ]
 │
 └── 4. รายงานและวิเคราะห์ (Dashboard & Monthly Reports)
 ├─► [ Dropdown] เลือก เดือน  ปี ที่ต้องการดูรายงาน
 ├─► [ Summary Cards] แสดง KPIs สรุปภาพรวม
 │ • ระยะทางรวม  ค่าน ้ามันรวม  อัตราสิ้นเปลืองเฉลี่ย ($กม.ลิตร$)
 ├─► [ Charts & Graphs]
 │ • Bar Chart เปรียบเทียบค่าน ้ามันแยกรายคัน
 │ • Pie Chart สัดส่วนการใช้งานแยกตามแผนก
 └─► [ Export Tools]
 • ปุ่ ม [ Export PDF ]
 • ปุ่ ม [ Export Excel  Google Sheets ]
